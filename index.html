Meus Projetos

Aqui você encontrará os links para alguns dos meus principais projetos em diferentes linguagens. Fique a vontade para acessar e entender cada código.

Site Portifólio

Este é o meu site portifólio! Todo o estilo e cores são originais. Inspirado no estilo Material Design do Google, este site trás um visual moderno e criativo, com cores suaves e harmônicas, além de um conjunto de fontes de alta legibilidade.

Expenses Control

O Expenses Control é uma ferramenta desenhada para ajudar usuários a gerenciar suas finanças pessoais de forma simples e elegante. A plataforma permite o cadastro de despesas, sua categorização e a visualização de resumos e totais através de um dashboard interativo.

Look At The Sky

Uma página web interativa que consome a API pública APOD (Astronomy Picture of the Day) da NASA. Este projeto permite que os usuários explorem incríveis imagens do espaço de forma dinâmica, pesquisem por imagens já carregadas e leiam suas respectivas descrições ou histórias.

Calculadora Forms C#

Esta é uma calculadora desenvolvida no Visual Studio com a tecnologia Forms C#, todo o visual e o design foram elaborados de maneira original por mim. Foi o meu primeiro contato com a linguagem C#.
